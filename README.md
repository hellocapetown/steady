# Steady: putting it online with GitHub Pages (free)

1. Sign in at github.com. Click the + at the top right, then New repository.
2. Name it `steady`, choose Public, tick Add a README (optional), and click Create repository.
3. Click Add file, then Upload files. Drag in index.html, manifest.webmanifest, sw.js, icon-192.png and icon-512.png from this folder (unzip it first). Click Commit changes.
4. Go to Settings, then Pages. Under Build and deployment, choose Deploy from a branch, pick main and the / (root) folder, and Save.
5. Wait 1 to 3 minutes. Your site will be at https://YOUR-USERNAME.github.io/steady/
6. Test on your phone. Android Chrome: menu, then Install app. iPhone Safari: Share, then Add to Home Screen.
7. To change anything later, upload the new file with the same name (Add file, Upload files) and commit. The change appears within a few minutes.

Tips: use the business email for the GitHub account, and write the page address in your notes. A custom web address can be added later.
